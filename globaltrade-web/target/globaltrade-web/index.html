Sign in

Authenticates through POST /api/auth/login, which issues a 5-minute HS256 access token plus a rotating refresh token.

Seeded accounts — admin@, coordinator@, customs@, warehouse@globaltrade.lk and rep@acme-supplies.com — all use the demo password above. Passwords are stored as PBKDF2-WithHmacSHA256 hashes at 210,000 iterations with a per-user salt; the token is held in memory only and is lost on refresh.
